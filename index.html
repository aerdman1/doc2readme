    Becomes a ReadMe category when you import the output.
    ReadMe's page contents panel stops at H3.

    Drop a Word or PDF document to get started
    Everything happens on this machine. Your files are never sent anywhere.
    ⌨️

    Real code blocks

    Word has no code block. Indented monospace paragraphs become fenced blocks with the language detected, so ReadMe highlights them and the copy button works.

    🩹

    AutoCorrect repair

    Word rewrites straight quotes to curly ones as you type. Snippets look fine in Word and fail when a developer pastes them. Fixed inside code.

    🗂️

    Clean structure

    Cover page, revision history and Word's table of contents dropped. Heading levels remapped so ReadMe's own title and contents panel work.

    📋

    Tables, images, callouts

    Tables converted with merged cells expanded, body images extracted, page logos skipped, and warning notes turned into ReadMe callouts.

    📄

    PDFs too

    A PDF stores glyphs at coordinates, not headings and tables, so those are rebuilt from font sizes and layout. It works well on text PDFs and needs a closer read than Word. Scanned pages need OCR first.
