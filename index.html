    100% Private Instant Processing No Uploads

    Real code blocks

    Word has no code block. Indented monospace paragraphs become fenced blocks with the language detected, so ReadMe highlights them and the copy button works.

    AutoCorrect repair

    Word rewrites straight quotes to curly ones as you type. Snippets look fine in Word and fail when a developer pastes them. Fixed inside code.

    Clean structure

    Cover page, revision history and table of contents dropped. Heading levels remapped so ReadMe's own title and contents panel work.

    Tables, images, callouts

    Tables converted with merged cells expanded, body images extracted, page logos skipped, and warning notes turned into ReadMe callouts.

    PDFs and Markdown too

    A PDF stores glyphs at coordinates, so structure is rebuilt from font sizes and layout. Existing Markdown gets cleaned and made MDX-safe.

    Images aren't uploaded for you. This page can't reach ReadMe, so extracted images are written into the images/ folder of the .zip and referenced by relative path. Upload them to ReadMe (or any host) and replace those paths with the full URLs. Images that were already full URLs in your document are left untouched and will keep working.
